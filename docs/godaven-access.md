# GoDaven access needed

GoDaven listings remain separate from saved shuls. A live integration needs an approved read-only API contract before it can be completed or tested. Public search results show partner integrations, but no official endpoint, authentication scheme, response schema, rate limit, or reuse terms for Shabbos Mode.

Request these details from GoDaven:

1. Permission for this personal Android beta to display nearby shuls and Friday/Shabbos minyan times, including any local cache needed for offline Shabbos display.
2. Read-only API documentation, test credentials, authentication requirements, and rate limits.
3. The meaning of schedule fields: local time zone, fixed versus zman based times, seasonal exceptions, holiday changes, and update timestamp.
4. Attribution, retention, redistribution, and public-release terms.

An API key alone is insufficient without the endpoint and data contract. Do not commit a key to this repository or embed a shared secret in a distributable APK. Keep saved shuls available if GoDaven fails or access is withdrawn.
