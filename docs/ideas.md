# Description
An app which adds features to make a smartphone useful on shabbos.
logo: power logo with candle for the stick in the ring.
# Features
## Theme
- Dark mode and light mode
- The idea is for low pixly animation style with a kind of scratchy look? reminds me of the game The Return of The Obra Dinn
## Alarms
Get a notification on Friday reminding to put in the times of the minyanim (maybe have OCR scan in). Have a button in the notification to keep last weeks (or just let them swipe away and default to last week).
- Start with just vibration then gradually raise the volume (customizable by user).
- Have 3 pleasant alarms by default.
- Import custom alarm.
- Set alarm volume.
- Play button to test it (with vibration).
- Alarm duration setting.
- Repeat alarms.
## Always on Display
Maybe can set times that it should be on and not blank. Time should always show though so maybe just leave it on all night.
- Display davening times, zmanim
- Hour by hour weather.  
- Vertical or horizontal.
- Quick call numbers (customizable, multiple).
- Triple tap to disable.
- If you miss minyan tell you where next one is  
- Tell user it's ok to leave the screen.
## Other
- Warn about alarms that are set in other apps that will ring on shabbos (even if the phone is off).
- Smart home automation based on zmanim and user inputted shul times.
- Tasker Integration.
- Auto Do Not Disturb on shabbos start and end.
- Get notification erev with a checklist of things to do before shabbos/yomtov.
- Get notification at set time on erev shabbos or yomtov that tells you when the zman is. It should auto update with a countdown of hours and minutes till the zman. GoDaven API, auto populate shul times, or Myzmanim, or Hebcal?
- Auto detect location and give you shul times.
- During week, auto do not disturb in shul use location. Auto SMS that DND is on.
- Use API to list nearby shuls and their zmanim.
- Give custom/display name to shul.
- Create API for shuls to add their times to.
- Shabbos mevarchim. when rosh chodesh is
- Github Actions if helpful
- Have a `docs` folder where all docs go.
- Create `.github/prompts` for implementing certain things for example: `feature.prompt.md` and `update-docs.prompt.md`
