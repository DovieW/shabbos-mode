- Simple setup for location, candle lighting, Shabbos end, and your community's zmanim calculation.
- Gra, Magen Avraham, and Chabad/Baal Hatanya options. Not sure displays both Gra and MGA Shema deadlines.

### Installing

Download `shabbos-mode-0.1.1.apk` from the assets below. The `.sha256` asset contains its checksum.

This uses the same release key as 0.1.0 and can update that signed release in place. Existing users finish setup using their saved location; local alarms, shuls, and checklist entries are retained.

Earlier debug installs use a different signing key and cannot update in place with this APK. Keep that installation until its data can be migrated; uninstalling deletes its local data.
