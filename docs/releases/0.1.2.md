## Cleaner onboarding

- Minimal welcome with the pixel candles, Get started, and Set up later.
- One decision per setup page, with Continue and Done fixed at the bottom.
- Zmanim preferences groups candle lighting, daytime calculation, and Shabbos ending. Gra, Magen Avraham, Chabad, and Show both are daytime choices, independent of Shabbos boundaries.
- Shorter location and timing copy. Help choosing and Other hold explanations and custom inputs.
- Deferred setup persists across restarts and can be resumed from Home. Location-dependent reminders and automation remain unscheduled while setup is deferred.

### Verification

10 unit tests, release lint, APK signature, version, and non-debuggable checks pass. Medium Android 16 emulator checks cover normal and 200% text, custom minute validation, saved choices, back navigation, skip/resume, and restart. Deferring setup removes a cached reminder; completing setup restores scheduling.

Galaxy checks for real alarms, reminder/DND/Tasker transitions, one-time device location success, and overnight battery behavior remain outstanding. This is a personal, noncommercial beta; GoDaven live access is pending. No phone audio or vibration was triggered during this release work.

### Installing

Download `shabbos-mode-0.1.2.apk` from the assets below. The `.sha256` asset contains its checksum.

This uses the same release key as 0.1.1 and can update that signed release in place. Completed setup and existing local data are retained.

Earlier debug installs use a different signing key and cannot update in place with this APK. Uninstalling deletes their local data.
