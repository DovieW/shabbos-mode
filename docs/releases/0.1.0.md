## Personal beta

- Alarms, a weekly preparation checklist, saved shuls and minyan times.
- Cached Hebcal times, hourly weather, an OLED clock, DND and Tasker integration.
- Paper and ink UI with Plex typography and the pixel candle logo.

### Verification

Release builds run unit tests, Android lint, signature verification, and APK identity/version checks. The UI has been reviewed on a medium Android 16 emulator, including large text, keyboard layouts, and the landscape clock.

The signed release APK also installs and opens on a fresh emulator, with the pixel candles as its launcher icon.

Full overnight battery behavior and real scheduled alarm, reminder, DND and Tasker transitions still require Galaxy checks. This is a personal, noncommercial beta. GoDaven live access remains pending.

### Installing

Download `shabbos-mode-0.1.0.apk` from the assets below. The `.sha256` asset contains its checksum.

This is the first APK signed with the persistent release key. Earlier desktop debug installs use a different key and cannot be updated in place. Uninstalling the debug app removes its local data; keep that installation until its data can be migrated. Subsequent signed releases will use the same release key.
